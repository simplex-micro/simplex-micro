# SimplEx Micro

**Predicate, don't speculate.**

The industry is solving memory latency with more memory. SimplEx solves it with scheduling.

SimplEx Micro is a self-funded startup building RISC-V vector processor IP for
deterministic, low-latency AI compute — from edge inference to
agented AI workloads. We publish open technical material here so
architects and engineers can evaluate the approach directly, not just
take our word for it.

## What's here

- **[riscv-vector-primer](https://github.com/simplex-micro/riscv-vector-primer)** —
  a technical guide to RISC-V vector processor architecture, written and
  maintained by our team. Read the chapters directly in the repo.
